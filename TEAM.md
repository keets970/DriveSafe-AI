## GitHub Collaboration

To allow teammates to contribute to the same repository, the repository owner can open:

**Repository → Settings → Collaborators (or Collaborators and teams) → Add people**

Search for each teammate's GitHub username and invite them. Each teammate must accept the invitation.

For a visible contribution history, each person should make genuine commits using their own GitHub account. Listing a person in this file does not automatically create a contribution on their GitHub profile.
